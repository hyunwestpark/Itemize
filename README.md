## 프로젝트 소개
Itemize는 블록체인 기술을 활용한 크라우드 펀딩 플랫폼입니다. 기존 크라우드 펀딩 시스템의 한계를 극복하고, 투자자와 프로젝트 창작자 모두에게 투명하고 효율적인 환경을 제공하는 기능을 개발했습니다. 스마트 컨트랙트를 통해 자금 조달 과정을 자동화하고, NFT 기반의 펀딩 참여 증명을 통해 투자 지분에 대한 유동성을 제공하고자 했습니다.

## 프로젝트 배경 및 목적

### 문제 🔍
기존 크라우드 펀딩 플랫폼에는 다음과 같은 문제점이 있습니다:
1. **유동성 부족**: 투자자들이 펀딩 참여 후 투자금을 회수하거나 재투자하기 어려움
2. **투명성 부족**: 자금 사용 내역 및 프로젝트 진행 상황에 대한 투명한 정보 공개 미흡
3. **보상 메커니즘 불명확**: 프로젝트 성공 시 투자자에게 돌아가는 보상 구조 불투명

### 프로젝트 목적 🎯
본 프로젝트의 주요 목적은 다음과 같습니다:
1. **크라우드 펀딩 자금의 유동성 제공**: NFT 및 토큰화를 통해 투자자가 언제든지 본인의 지분을 거래할 수 있는 시스템 구축
2. **펀딩 지분에 대한 성과 제공**: 프로젝트 성공에 따른 수익 분배 메커니즘 구현
3. **블록체인 기반 투명성 확보**: 스마트 컨트랙트를 통한 자금 흐름 및 거래 내역의 완전한 투명성 제공

## 주요 기능

### 사용자 측면
- **지갑 생성 및 관리**: 암호화폐 지갑 생성 및 관리 기능 (니모닉 구문 방식 적용)
- **프로젝트 탐색 및 검색**: 다양한 카테고리별 프로젝트 검색 및 필터링
- **NFT 티켓**: 프로젝트 투자 증명을 위한 NFT 티켓 발급 및 관리
- **프로젝트 투자**: 암호화폐를 통한 간편한 투자 프로세스
- **투자 현황 모니터링**: 실시간 펀딩 진행 상황 및 투자 포트폴리오 확인

### 프로젝트 창작자 측면
- **프로젝트 등록**: 간편한 프로젝트 등록 및 관리 기능
- **펀딩 현황 확인**: 실시간 펀딩 진행 상황 모니터링
- **업데이트 공유**: 프로젝트 진행 상황 공유
- **NFT 티켓 발행**: 투자자를 위한 NFT 티켓 생성 및 발행

### 플랫폼 기능
- **스마트 컨트랙트 자동화**: 프로젝트 펀딩 조건 충족 시 자동 실행되는 계약
- **토큰 경제 시스템**: 플랫폼 내 거래 및 보상을 위한 자체 토큰 시스템 (PNP 토큰)
- **2차 거래 시장**: 투자 지분(NFT 티켓)의 유동성을 위한 거래 시장 제공

## 기술 스택 💻
- **프레임워크**: React.js
- **상태 관리**: Redux
- **스타일링**: Tailwind CSS, Material Tailwind
- **통신**: Axios
- **라우팅**: React Router

## 기술적 도전과 해결 방법

### 성능 최적화 도전 ⚡
프로젝트 진행 중 상품 목록 페이지에서 로딩 시간 문제가 발생했습니다. 각 상품 카드마다 독립적인 API 호출이 발생하여 페이지 로딩이 지연되었습니다.

#### 문제 상황 ❌
- 각 상품 카드가 렌더링될 때마다 개별적으로 투자자 데이터를 요청하는 API 호출 발생
- 투자 진행률 계산이 반복 실행되어 성능 저하
- 10개의 카드가 있을 경우 10번의 API 호출이 발생하는 구조적 문제

#### 해결 방안 ✅
1. **클라이언트 단 캐싱 구현**
   - React의 useRef 훅을 활용하여 이미 요청한 데이터를 캐싱
   - 리렌더링 시 불필요한 API 호출 감소

2. **스켈레톤 UI 도입**
   - 데이터 로딩 중 사용자 체감 시간 감소를 위한 스켈레톤 UI 구현
   - 점진적 데이터 로딩으로 UX 개선

3. **상태 관리 최적화**
   - Redux를 활용한 효율적인 상태 관리로 불필요한 리렌더링 방지
   - 상태 업데이트 로직 최적화

#### 배운 점 💡
이러한 노력으로 페이지 내 리렌더링 성능은 개선되었으나, API 구조상 첫 로딩 시 개별 요청이 필요한 부분은 제약이 있었습니다. 프로젝트 초반 기능명세를 구체적으로 작성하지 않아 백엔드에서 일괄 처리 API를 만들지 못한 것이 기술 부채로 발생했습니다. 해당 프로젝트를 통해 요구사항 정의 단계에서 철저한 검증의 중요성을 배울 수 있었습니다.
